# For AI coding agents working in this repository

Commits here carry people's names only.

- Commit as the person running the session, under their own GitHub identity: set
  `git config user.name` and `git config user.email` to their name and GitHub noreply address
  before the first commit. Never commit as "Claude" or under any other tool identity.
- Do not add `Co-Authored-By:` lines, "Generated with ..." lines, or any other tool attribution to
  commit messages or pull request descriptions.
